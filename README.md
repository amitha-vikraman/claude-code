# Overview

This repository contains reusable resources for building with Claude Code, including:

- `spec.md` templates
- reusable prompts
- command patterns
- AI workflow examples
- agent orchestration ideas
- coding standards
- project starter structures
- automation references

The goal is to create a centralized knowledge base for faster and more structured AI-assisted development.
